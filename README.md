# التقرير الأدبي | فرقة أشبال الصنوبر

منصة ويب تفاعلية لتوثيق وعرض أنشطة **فرقة أشبال الصنوبر** خلال الموسم الكشفي **2025–2026**.

## نبذة عن المشروع

يعرض الموقع حصيلة الموسم في واجهة عربية من اليمين إلى اليسار (RTL)، مع بطاقات للأنشطة ومعلوماتها الأساسية، وأقسام مخصصة لمشروع الفرقة **ECO ART** وقراءة أولية في حصيلة الموسم.

## المزايا

- عرض الأنشطة المسجلة وعددها 18 نشاطًا.
- البحث في أسماء الأنشطة والتواريخ والأماكن والمشاركين والتفاصيل.
- تصفية الأنشطة حسب المجال أو السنة.
- عرض تفاصيل كل نشاط في نافذة منبثقة.
- اختيار صورة من الجهاز لمعاينتها داخل بطاقة النشاط.
- تصميم متجاوب مع الهواتف والأجهزة اللوحية والحواسيب.
- تنسيق مناسب للطباعة.
- واجهة عربية RTL بألوان الهوية البصرية الزرقاء والصفراء.

## التقنيات

- HTML5
- CSS3
- JavaScript (Vanilla)
- خط Cairo من Google Fonts

لا يتطلب المشروع إطار عمل JavaScript أو عملية بناء (build).

## تشغيل المشروع محليًا

1. نزّل المستودع أو استنسخه:

   ```bash
   git clone https://github.com/USERNAME/REPOSITORY.git
   cd REPOSITORY
   ```

2. افتح `index.html` مباشرة في المتصفح.

   ويمكنك أيضًا تشغيل خادم محلي بسيط من مجلد المشروع:

   ```bash
   python -m http.server 8000
   ```

   ثم افتح <http://localhost:8000>.

## بنية المشروع

```text
REPOSITORY/
├── index.html
├── README.md
└── assets/          # موارد إضافية إن أُضيفت للمشروع
```

النسخة الحالية من `index.html` تتضمن CSS وJavaScript داخل الملف نفسه، كما أن الشعارات الظاهرة في الترويسة مضمنة داخله بصيغة Base64. مجلد `assets/` ليس مطلوبًا لتشغيل هذه النسخة ما لم تُضف إليه ملفات ويُحدّث HTML لاستخدامها.

## الصور وحفظ التعديلات

زر **إضافة صورة** يتيح اختيار صورة ومعاينتها في بطاقة النشاط الحالية. المعاينة محلية داخل الصفحة فقط؛ الصور المختارة بهذه الطريقة لا تُرفع إلى GitHub ولا تُحفظ تلقائيًا بعد إعادة تحميل الصفحة أو فتح الموقع على جهاز آخر.

لإظهار صور ثابتة لجميع الزوار، أضف الصور إلى المستودع (مثلًا داخل `assets/images/`) ثم اربطها بعناصر الصفحة باستخدام مسارات نسبية.

## النشر عبر GitHub Pages

1. ارفع `index.html` إلى الفرع `main` في المستودع.
2. افتح **Settings → Pages** في GitHub.
3. ضمن **Build and deployment** اختر **Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.

بعد اكتمال النشر، سيعرض GitHub رابط الموقع في صفحة Pages. إذا كان المستودع باسم `USERNAME.github.io` فسيكون عادةً على النطاق `https://USERNAME.github.io/`، أما المستودعات الأخرى فتكون عادةً على `https://USERNAME.github.io/REPOSITORY/`.
